# 手机模型选择与 Magpie 适配

## 目标和使用方式

本机和远程连接共用模型目录，选择器要能在大量渠道、模型和路由中快速定位。手机上使用一列可滚动分类和一列惰性加载的结果：全部、星标、Magpie 路由组及各供应商；顶部支持搜索名称、渠道、供应商、路由和模型 ID，底部保留当前模型支持的思考深度。管理入口移到标题栏，为结果留出更多空间。分类和模型列表均为滚动条留出独立空隙，避免遮盖选中框和点击区域；分类高度随内容与字号适配。小屏大字号或横屏时，思考深度以可展开菜单呈现，给模型列表保留空间。搜索框与底部思考深度始终固定，分类与结果独立滚动；键盘出现时标题让出空间，思考深度仍固定在键盘上方。

收藏存储在手机本地，按连接、原始渠道和模型 ID 区分；不写入 Magpie 或远程主机。保存失败会提示重试，未成功的收藏不会被当作已保存。

## 兼容边界

- 目录仍来自 DSH 的 `session/modelCatalog`；对官方接入的 `magpie` 系列渠道以及 DSH 中以 Magpie 命名生成的 `custom-magpie` 系列渠道，按 `provider/model`、`group/...` 与 `auto/...` 做展示分组。其他自定义渠道名称无法可靠识别为 Magpie，仍按原渠道显示。选定时始终传回目录中原始 provider 和 model ID，不改写路由。同名模型在不同协议渠道下各自保留。
- Magpie 旧配置可能存在叫 `auto` 的自定义供应商，因此 `auto/...` 归入路由组仅是界面展示规则，不改变请求。DSH 目录没有完整的 Magpie 自定义供应商资料和路由成员信息，无法准确重现 Magpie 管理页面中所有自定义名称或叠加头像。
- 已识别的品牌显示图标；未知渠道或模型使用文字占位，不臆造品牌归属。图标取自 Magpie 固定版本，其文档注明品牌图标来自 Lobe Icons。两者均为 MIT，来源、版权和许可见 `THIRD_PARTY_NOTICES.md` 与 App 内第三方许可页。品牌商标仍归各自所有者。

## 证据和验证

`app/test/chat/goldens/model_picker_magpie_dark.png` 为 390×844 逻辑像素的 Flutter 组件测试截图，目录为合成的 138 项数据，并非用户真实目录。相关测试覆盖精确路由、按连接区分本地收藏、重读、保存失败重试、独立滚动、惰性渲染、320 像素宽屏幕、键盘和字体放大。实际 Android 设备与真实 Magpie 数据的验证仍需后续安装测试。本轮没有构建或推送。
